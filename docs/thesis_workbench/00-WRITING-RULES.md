# Writing Rules

## 文风规则
- 以软件工程毕业论文语体写作，避免口语化。
- 每节建议采用：问题背景 -> 设计方案 -> 实现与效果。
- 避免大段空泛描述，尽量绑定项目证据。

## 术语统一
- 用户角色：学生、校友、教师、管理员。
- 技术术语：微信小程序、云函数、云数据库、OPENID。
- 状态术语：pending、processing、accepted、rejected、published。

## 章节写作强制项
- 第 2 章必须包含功能需求与非功能需求。
- 第 3 章必须包含总体架构与模块划分。
- 第 4 章必须包含数据库设计与状态机设计。
- 第 5 章必须包含关键页面与关键云函数实现。

## 图表规则
- 每张图必须有编号与图注。
- 图中术语必须与正文一致。
- 复杂时序图来不及时，可用结构化表格替代并在正文说明。

## 一致性规则
- 任何“已实现”结论必须能在代码中找到。
- 出现冲突时执行 `00-SOURCE-OF-TRUTH.md` 的优先级。
