# 表4-4 申请处理阶段说明表

| 处理阶段 | 责任角色 | 主要操作 | 输出结果 | 说明 |
|---|---|---|---|---|
| 待处理阶段（pending） | 校友 | 查看申请信息，进入处理流程 | 进入处理中或给出处理结果 | 该阶段为申请初始阶段 |
| 处理中阶段（processing） | 校友 | 比较候选人信息并作出决策 | 接收或拒绝结果 | 该阶段用于业务处理与筛选 |
| 已接收阶段（accepted） | 校友、学生 | 校友完成接收，学生查看结果 | 学生可见后续联系信息 | 该阶段为处理完成状态 |
| 已拒绝阶段（rejected） | 校友、学生 | 校友完成拒绝，学生查看结果 | 学生收到拒绝反馈 | 该阶段为处理完成状态 |

来源：作者根据系统流程整理
