# 表4-6 关键控制措施表

| 控制措施 | 适用环节 | 主要做法 | 目的 |
|---|---|---|---|
| 身份控制 | 登录与业务访问 | 由服务端识别用户身份 | 防止伪造身份发起请求 |
| 角色控制 | 发布、审核、统计等关键操作 | 按角色限制可执行功能 | 防止越权操作 |
| 归属控制 | 申请处理 | 校验操作人与资源归属关系 | 防止他人篡改处理结果 |
| 字段控制 | 发布与申请写入 | 仅接收业务所需字段 | 防止无关字段写入 |
| 信息分级控制 | 职位详情展示 | 按申请结果控制敏感信息可见范围 | 防止敏感信息提前暴露 |
| 流程控制 | 申请处理过程 | 仅允许在规定阶段内处理申请 | 防止流程处理混乱 |

来源：作者根据系统控制策略整理
