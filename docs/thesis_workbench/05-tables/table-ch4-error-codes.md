# 表4-5 异常处理策略表

| 异常类型 | 典型场景 | 形成原因 | 处理方式 | 用户提示建议 |
|---|---|---|---|---|
| 参数异常 | 提交参数不完整 | 必要字段缺失或格式不符合要求 | 拒绝处理并返回提示 | 提示用户补充完整信息 |
| 身份异常 | 用户身份不可用 | 登录状态失效或身份未初始化 | 引导用户重新登录 | 提示用户先完成登录 |
| 权限异常 | 无权执行操作 | 角色与操作要求不匹配 | 拒绝执行目标操作 | 提示用户当前无操作权限 |
| 数据异常 | 目标记录不存在 | 数据已变更或目标已删除 | 终止本次操作并刷新数据 | 提示用户刷新后重试 |
| 业务冲突 | 重复申请或流程冲突 | 当前业务状态不允许重复处理 | 保持原状态并返回冲突提示 | 提示用户当前操作不可重复 |
| 系统异常 | 服务运行异常 | 运行过程出现异常中断 | 返回失败信息并记录日志 | 提示用户稍后再试 |

来源：作者根据系统处理策略整理
